
# ArqComp — Jogos de Arquitetura Computacional

Plataforma educativa desenvolvida para a Atividade Avaliativa III da disciplina de Arquitetura Computacional — Sprint 3.

## Objetivo

Revisar conceitos relacionados à arquitetura e aos componentes de um computador por meio de jogos educativos interativos.

## Jogos disponíveis

### 1. Palavras cruzadas

Atividade com 12 conceitos de Arquitetura Computacional, pistas horizontais e verticais, preenchimento de letras e correção automática.

### 2. Complete a Arquitetura

Jogo de associação com 8 frases. O jogador deve arrastar as respostas corretas até as lacunas correspondentes.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript puro

- index.html — Menu principal

- associacao.css — Estilos do segundo jogo
- associacao.js — Lógica de associação
