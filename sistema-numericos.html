Conheça os sistemas numéricos

DECIMAL · BASE 10

Utiliza os algarismos de 0 até 9. Cada posição representa uma potência de 10.

BINÁRIO · BASE 2

Utiliza apenas 0 e 1. Cada posição representa uma potência de 2.

OCTAL · BASE 8

Utiliza os algarismos de 0 até 7. Cada algarismo corresponde a 3 bits.

HEXADECIMAL · BASE 16

Utiliza números de 0 até 9 e letras de A até F. Cada algarismo corresponde a 4 bits.
